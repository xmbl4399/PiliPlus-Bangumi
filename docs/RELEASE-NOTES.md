基于 PiliPlus 2.2.1-ohos-3（鸿蒙版）二次开发，接入 Bangumi（bgm.tv）数据。

## 新增

- 首页顶栏「番剧 / 影视」整体替换为 Bangumi 数据源
  - 番剧：新番表 / TV / WEB / OVA / 剧场版
  - 影视：日剧 / 欧美剧 / 华语剧 / 韩剧 / 电影
- 新番表：按星期分组、今天优先、空分组保留、下拉刷新
- 年/月浏览：年份切换（2006 ~ 当前年）、12 个月渐进加载、月份倒序分组
- 卡片：评分角标、TV 集数角标、题材 tag；TV 番剧的题材 tag 贴在封面左上角
- 点击卡片跳转 B 站搜索（关键词为 bgm 标题）
- 数据层：官方 + 2 个社区反代多源兜底与重试；月缓存（当季 6 小时 / 历史 30 天）
- 设置 → 其他设置：BGM 接口源、隐藏无评分条目、显示题材标签、TV 显示集数

## 说明

- 本包为 **未签名** release HAP，安装前需自行签名
- 版本：`2.2.1-ohos-3`（versionCode 6620）
- 仅鸿蒙端；B 站原有的「我的追番 / 追番时间表」已移除
