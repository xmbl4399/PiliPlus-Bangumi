基于 PiliPlus 2.2.1-ohos-3（鸿蒙版）二次开发，接入 Bangumi（bgm.tv）数据。

## 本次更新（第二版）

- **加载动画改为 PiliPlus 骨架屏**：复用 `Skeleton` shimmer，移除转圈与顶部进度条
- **月份页流式加载**：首屏只预取 2 个月，滚动到距底 800px 自动加载下一月；切年份/刷新会丢弃过期请求
- **新番表缓存 60 分钟**：对齐 `/calendar` 的 `max-age`，返回再进不再重复请求
- **空结果短缓存 30 分钟**：避免刚开播的新番被 6h/30d 缓存长期钉住
- **设置 → 其他设置新增「清理番剧缓存」**：清理后自动刷新当前页面
- 修复两行标题卡片 6px 溢出、TV 卡片底部多余留白
- 连续空月份最多自动跳过 2 个；内容不足一屏时自动补拉（最多 3 次）

## 功能（累计）

- 首页顶栏「番剧 / 影视」整体替换为 Bangumi 数据源
  - 番剧：新番表 / TV / WEB / OVA / 剧场版
  - 影视：日剧 / 欧美剧 / 华语剧 / 韩剧 / 电影
- 新番表：按星期分组、今天优先、空分组保留、下拉刷新
- 年/月浏览：年份切换（2006 ~ 当前年）、月份倒序、骨架 + 流式加载
- 卡片：评分角标、TV 集数角标、题材 tag；TV 题材 tag 贴在封面左上角
- 点击卡片跳转 B 站搜索
- 数据层：官方 + 2 个社区反代多源兜底与重试
- 缓存：月份（当季 6h / 历史 30d / 空 30min）、新番表（60min）
- 设置：BGM 接口源、隐藏无评分、显示题材标签、TV 显示集数、清理番剧缓存
